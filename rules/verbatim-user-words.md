# Verbatim User Words — VITAL NON-NEGOTIABLE

IF YOU SEE IT, AN LLM SEES IT, OR AN AGENT SEES IT: YOU MUST ABSOLUTELY PREFER VERBATIM WHAT ISAAC TOLD YOU TO SAY TO IT.

When writing rules, prompts, skills, concepts, code comments, system prompts, CartON concepts, or ANYTHING that will be read by any system or agent: use Isaac's exact words. Do not paraphrase. Do not rephrase. Do not summarize. Your rewording must always preserve the information. Never lose information because of improving the wording of what the user says.

Never write fragments that can be interpreted as the opposite of the intended meaning. Every literal fragment must only be interpretable as a command in the direction of correct behavior.

Example: "Your rewording loses information" — an LLM reads "loses information" as a literal command fragment. Correct version: "Your rewording must always preserve the information. Never lose information because of improving the wording of what the user says."
